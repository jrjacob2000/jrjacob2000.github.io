This Privacy Policy explains how the JRJacob Application Launchpad (https://jrjacob2000.github.io/) and its three web applications handle user data, browser storage, and optional cloud synchronization.

2. Data Collected on the Launchpad Portal

  • No Personal Data Collection: The root Launchpad page (jrjacob2000.github.io) does not require sign-in, does not collect personal information, and does not use tracking or advertising cookies.
  • Local Preferences Only: The Launchpad stores only your optional UI preferences in your browser's localStorage (such as which app tile you pinned first, your last-opened app shortcut, and whether links open in the same tab).

3. Data Handling in Individual Suite Applications

  • Google Drive JSON Storage (GraceBooks & CapitalFlow): When you choose to connect your Google account inside GraceBooks or CapitalFlow, those applications request the narrow drive.file scope to store and synchronize only the JSON backup files created by the application inside your own personal Google Drive.
  • Collaborative Cloud Ledger (Clan E-Fund Ledger): Stores authorized family member contribution records, medical disbursements, and BPI fund allocations in a role-protected Firebase Firestore database for participating clan members.
  • No Sale or Third-Party Sharing: User data and financial records across all JRJacob applications are never sold, rented, shared with advertisers, or used to train artificial intelligence models.

4. Google API Services User Data Policy (Limited Use Disclosure)

Where any JRJacob application accesses Google APIs (such as Google Sign-In or Google Drive drive.file), its use and transfer of information received from Google APIs strictly adheres to the Google API Services User Data Policy , including the Limited Use requirements.
